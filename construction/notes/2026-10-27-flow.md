|---|---|---|
| Why comment the issue to validate it, if the label is removed? | The comment is the trace a fresh agent reads (what was validated, when); the label only says nobody waits | contributing.md, "The maintainer's morning" |
| How to switch a PR to `Closes #n`? | Edit the PR body, not a comment; `Refs` links nothing in the Development section | decision issue-defines-pr-verifies |

| Does `state:` duplicate `is:open/closed`? | It splits `open` in three; it is a derivable copy, so it drifts; a Project corrects that | decision state-labels-until-the-project; issue #64 |
| Are the milestones one-shot? | Per stage during the construction, per release afterwards | decision milestones-per-stage-then-release |

| Squash commits without the PR title? | Repository setting: squash title and message from the PR; branch deleted at merge; done in the web interface | contributing.md, "A branch becomes a pull request" |
| A signature line at the end of PR bodies? | No: the squash takes the body as the commit message; the Co-Authored-By trailer is enough | `/finish` step 5 |
| CLI or web interface for the maintainer's own actions? | The web interface, with the menu path; commands only for what it cannot do | contributing.md, "The maintainer's morning" |
