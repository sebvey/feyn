# courses

The courses, one folder each, `courses/<id>/`. A course holds its `course.yaml` (identity, spec version), its plan, glossary, storyline, domains, concepts and decisions. The folder holds no course until the founding course, migrated from the frozen repository and archived at a tag of the history, is re-created through the creation path (epic #520, whose Material says where it is read). The bench every change of the spec is tried on is not here: it is the spec's sample course, `product-lines/linear-fr/1/course/samples/cafe/`. Course material is in French and is never translated.
