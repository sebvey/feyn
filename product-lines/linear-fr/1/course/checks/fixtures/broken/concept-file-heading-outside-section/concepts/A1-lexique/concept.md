# Annexe A1 : Le lexique

## L'essentiel

Le lexique rassemble les mots du cours.

## Section A1a : Les mots

### Unité A1a1 : Un mot

#### Leçon

- **Matière** : Chaque mot du **lexique** [a une définition courte](cours:S2 "definition-courte").
- **Idées fausses** :
  - **Un tableau** : « Un tableau »
    - **Racine** : la phrase se lit vite ainsi.
    - **Correction** : c'est une carte.

#### Cas du fil rouge

##### Cas : Le cas A1a1

- **Ancrage** : Régis regarde une carte.
- **Question** : que voit-il ?
- **Réponse attendue** : une carte.
- **Idées fausses en jeu** : Un tableau

##### Cas : Le cas A1a1, encore

- **Ancrage** : Le même cas, une autre fois.
- **Question** : La même question ?
- **Réponse attendue** : La même réponse.
- **Idées fausses en jeu** : Un tableau

### Unité A1a2 : Sa définition

#### Leçon

- **Matière** : La définition d'un mot tient en une ligne, celle de **produit** comprise.
- **Idées fausses** :
  - **Une page** : « Une page »
    - **Racine** : la phrase se lit vite ainsi.
    - **Correction** : une ligne suffit.

#### Cas du fil rouge

##### Cas : Le cas A1a2

- **Ancrage** : Régis cherche un mot du lexique.
- **Question** : combien de lignes a sa définition ?
- **Réponse attendue** : une.
- **Idées fausses en jeu** : Une page

##### Cas : Le cas A1a2, encore

- **Ancrage** : Le même cas, une autre fois.
- **Question** : La même question ?
- **Réponse attendue** : La même réponse.
- **Idées fausses en jeu** : Une page
